- 迁移 `2026_09_25_005` 创建 `projects`、`datasets`、`dataset_fields`、`dataset_schema_versions`，为 `workflows` 增加 `project_id` 和 `dataset_id`。

- 数据集 Schema 包括字段类型、必填/多值、唯一键字段和空值策略。更新 Schema 产生新版本，旧版本的字段、唯一键和空值策略仍可读取。A02 的正式记录写入会消费这些定义；A01 不改变采集执行结果。
- 新建工作流必须关联同项目、同记录类型的数据集。旧磁力 provider 后续自动生成的默认工作流会归入默认项目及磁力数据集。

## 接口与界面

受认证保护的 `/api/v2` 接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/projects/list`、`/projects/create` | 查询、新建项目 |
| POST | `/projects/update` | 更新名称、目标、负责人和状态 |
| GET/POST | `/datasets/list`、`/datasets/create` | 可按 `project_id` 查询、新建数据集 |
| GET | `/datasets/detail?id=…&version=…` | 读取当前或指定版本的字段 Schema |
| POST | `/datasets/schema/update` | 原子创建下一 Schema 版本 |
| GET | `/workflows/list?project_id=…&dataset_id=…` | 查询采集器归属 |

`web/` 新增“项目与数据集”入口，使用真实 API 展示项目、数据集和采集器归属，支持创建项目、创建数据集及修改字段 Schema。页面采用 v2.1 原型最终生效的蓝灰配色、卡片层级和窄屏布局；完整应用外壳与工作台视觉改造仍属于 A06。
