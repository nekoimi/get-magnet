# A03 获取适配器落地记录

日期：2026-09-26。主项目和 `scrapio-browser` 的代码已实现；真实 CloakBrowser 浏览器环境的逐动作联调待执行，因此实施计划中的 A03 暂不勾选。

## 定义与执行

`trigger.fetch.mode` 可选 `http`（默认）或 `browser`。普通 HTML 和 JSON 页面由 Go HTTP GET 获取；浏览器模式才调用 gRPC。`timeout_ms` 最大 120000。浏览器动作配置在 `trigger.fetch.actions`，按顺序支持 `navigate`、`wait`、`click`、`input`、`scroll`，最多 32 个。动作可用 `run_on=trigger/detail` 限定页面角色，缺省应用于所有页面。`navigate.value` 须为绝对 HTTP(S) URL；`wait/click/input.selector` 必填；`scroll.value` 是 -100000 至 100000 的像素整数。动作超时最大 60000 毫秒。未实现的模式、动作和字段会在发布校验时报错。JS 脚本动作、Profile、Headers 和会话配置仍未开放给工作流定义。

```json
{
  "trigger": {
    "type": "manual",
    "url": "https://example.org/detail",
    "fetch": {
      "mode": "browser",
      "timeout_ms": 60000,
      "actions": [
        {"type": "wait", "selector": "#ready", "timeout_ms": 10000},
        {"type": "scroll", "value": "600"}
      ]
    }
  },
  "nodes": [
    {"name": "extract", "type": "extract", "config": {"fields": [{"name": "number", "selector": "article", "attribute": "data-code"}]}}
  ]
}
```

统一结果包含获取方式、请求 URL、最终 URL、HTTP 状态码、内容类型、HTML/JSON 内容、耗时与浏览器动作结果。浏览器无法报告导航 HTTP 状态时状态码为 `0`，不伪造为 200。成功结果写入 `documents.metadata`，失败的获取阶段、错误码、状态码、是否可重试和动作回执写入任务尝试快照。工作流用最终 URL 解析相对链接。HTTP 响应体上限为 10 MiB；非 2xx、格式错误和过大响应分别归因。浏览器 gRPC 是按需连接，服务暂时不可用不阻塞 Go 控制平面启动。

## 协议与部署

`scrapio-browser/proto/fetch.proto` 增加最终 URL、状态码、内容类型和逐动作结果，两个仓库的生成代码已同步。浏览器执行器对尚未实现的 Profile/Headers 明确返回 `UNSUPPORTED_OPTION`。部署时先更新浏览器服务，再更新主项目；旧浏览器服务不会返回动作回执，也不支持滚动。

旧工作流版本以前默认调用浏览器。迁移 `20260926001` 为既有定义补上 `trigger.fetch.mode=browser`，保持历史执行行为；新建定义缺省使用 HTTP。在开发库迁移前保存了工作流版本的本机表数据快照，1 个旧定义完成补写，重跑迁移没有再次修改数据。该快照不是完整数据库备份。
