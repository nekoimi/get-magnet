# A06 首次使用界面与视觉基础落地记录

日期：2026-09-26。

## 交付范围

- `web/` 的默认入口改为 `/workspace/projects`。工作区按[管理界面交互原型](管理界面v2.1交互原型.html)建立深蓝侧栏、项目切换、蓝灰背景、卡片、状态、表格及检查面板；窄屏使用可收起导航。旧页面保留入口供历史能力使用。
- 项目页提供空状态、创建项目、目标数据集、采集器及最近运行入口。数据页提供 Schema 字段和唯一键配置、记录列表，以及记录的观察、修订、运行与原始文档追溯。
- 采集器支持单页 HTML 与 JSON 接口向导，按目标数据集生成初始字段规则；进入工作台后可修改入口、获取方式、CSS/JSONPath、JSON 数组路径，保存版本样例，查看字段级步骤和预计保存决策，回归、发布、手动运行。高级 JSON 与同一工作流定义双向同步。旧磁力等不属于本工作台能力范围的定义只提示，不用通用表单误编辑。
- 运行页按项目筛选，显示状态、摘要、页面任务、错误及原文。项目/采集器/运行的列表和详情在界面核对当前项目归属。后端运行列表增加 `project_id`、`workflow_id` 过滤参数。

当前向导依赖 A04/A05 已支持的节点和提取器。模板默认选择器是编辑起点，用户须按目标页面调整；发布前仍由后端校验定义和全部样例。凭据引用尚无已联通的控制平面解析链，当前表单不暴露凭据字段；后端拒绝包含未实现凭据配置的发布。
