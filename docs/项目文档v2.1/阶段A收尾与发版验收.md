## 发版验收清单

以下需要在实际部署环境执行；开发库与模拟页面的测试不能替代它们。

1. **数据库**：完整备份 PostgreSQL；部署迁移后核对旧工作流、默认项目归属、磁力 `resources` 到 `records` 的映射数量及异常数；重复执行迁移核对幂等。保留旧表和备份作为回退依据。
2. **首次使用**：登录后创建项目、文章和磁力数据集；修改 Schema 并读取新旧版本；在桌面和窄屏确认编辑、保存和刷新后的内容。
3. **HTTP HTML**：从单页模板创建非磁力采集器；保存有效与缺唯一键样例，检查每份回归结果及发布阻断；移除失败样例、发布、手动运行，核对记录、观察、修订、运行、页面任务、原始文档及版本链接。
4. **HTTP JSON**：配置对象数组路径和字段路径，重复第 3 步；核对一页多条候选、同键更新与跨来源观察。
5. **磁力页面**：用磁力数据集生成单页采集器，将 `canonical_key` 指向页面番号、`links` 指向磁力链接并开启多值；预览后发布和运行，确认通用 `records` 中的键和链接、来源证据。旧 `magnets`/`resources` 仍保留。
6. **真实浏览器**：在已配置 CloakBrowser Manager 的 `scrapio-browser` 环境依次验证导航、等待、点击、输入、滚动；核对最终 URL、动作回执、文档和失败任务快照。逐项成功后再勾选 A03。Profile、Headers、会话和凭据引用目前未开放，不能作为已交付能力验收。

阶段 A 的真实环境整体验收以以上结果为准。若发现发布阻断、数据不一致或动作回执缺失，记录工作流版本、运行 ID、任务 ID 与样例 ID 后修复；本记录不将未执行的发版测试记作通过。
